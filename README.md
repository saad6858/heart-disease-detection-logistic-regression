# Heart Disease Detection Model

Assignment — Bano Qabil Agentic AI Program

## Overview
Supervised machine learning project that predicts heart disease presence using the UCI Heart Disease dataset.

## What is included
- Data loading and inspection
- Preprocessing and feature preparation
- Logistic Regression model training
- Evaluation (accuracy, confusion matrix, classification report)
- Inference on a new patient sample

## Model
- Algorithm: Logistic Regression
- Task: Multi-class classification (target classes 0–4)
- Test Accuracy: \~50.5%

## Notes
This project focuses on the complete training pipeline rather than high accuracy. It served as foundational practice before moving into agentic systems.

## Tech
- Python
- pandas, scikit-learn, matplotlib, seaborn
